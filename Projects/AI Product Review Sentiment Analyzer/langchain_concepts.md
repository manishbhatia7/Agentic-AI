# LangChain Concepts and Usage

| Concept | Usage |
|---|---|
| ChatOpenAI | LLM |
| System / Human roles | Role-based prompts |
| ChatPromptTemplate | Prompt creation |
| Pydantic | Structured output |
| PydanticOutputParser | Output validation |
| StrOutputParser | Text output |
| RunnableSequence | Chain execution |
| RunnableLambda | Data transformation |
| RunnablePassthrough | Preserve/add data |
| RunnableBranch | Conditional routing |
| MessagesPlaceholder | Chat history |
| RunnableWithMessageHistory | Conversation memory |
